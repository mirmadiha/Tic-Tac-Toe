# Tic-Tac-Toe Game 🎮

Live demo: [Netlify → https://your-netlify-link.netlify.app](https://winning-line.netlify.app)

A simple two-player browser game built with HTML5, CSS3 & JavaScript (ES6+).  
Features turn-based gameplay (X vs O), win/draw detection, and a responsive UI.

## Built With  
HTML5 · CSS3 · JavaScript
